GitHub 镜像加速

GitHub 链接会自动生成加速镜像。发布包下载校验 manifest 中的 SHA-256，镜像只改变传输路径，不改变校验结果。

可在客户端设置 NEKO_DISABLE_GITHUB_MIRROR=1 关闭自动镜像；也可在运行时 manifest 里用 mirrors 指定自己的镜像模板（{url} 占位）。

运行时独立下载

MSI 默认不含 Android 运行时。首次使用时，在主窗口填写运行时 manifest 地址，或调用 MCP 工具：

neko_download_runtime {"manifest":"https://…/runtime.json"}

manifest 格式：

{"url":"https://github.com/…/runtime.zip","sha256":"…","bytes":123,"mirrors":["https://your-mirror/{url}"]}
